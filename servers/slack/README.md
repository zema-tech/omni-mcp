# Slack MCP Server (OmniMCP)

> High-quality Model Context Protocol server for Slack.

**Status:** Planned / Coming soon

## Planned Tools

- `slack_send_message` – Send a message to a channel or user
- `slack_list_channels` – List channels the bot has access to
- `slack_get_channel_history` – Read recent messages
- `slack_search_messages` – Search across the workspace
- `slack_list_users` – List workspace members
- `slack_add_reaction` – Add emoji reactions
- `slack_create_channel` – Create a new channel
- `slack_invite_to_channel` – Invite users

## Auth

- Bot Token (OAuth)
- User Token (for some actions)

## Why we build this

Slack does not yet have a widely adopted official MCP server.  
This one will be fully open source and production-ready.
