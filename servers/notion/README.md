# Notion MCP Server (OmniMCP)

> High-quality Model Context Protocol server for Notion.

**Status:** Planned / Coming soon

## Planned Tools

- `notion_search` – Search pages and databases
- `notion_get_page` – Get page content
- `notion_create_page` – Create a new page
- `notion_update_page` – Update page properties / content
- `notion_query_database` – Query a database with filters
- `notion_create_database_item` – Add a row to a database
- `notion_list_users`
- `notion_append_blocks`

## Auth

- Internal Integration Token
- OAuth (public integrations)
