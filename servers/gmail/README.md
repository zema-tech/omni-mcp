# Gmail MCP Server (OmniMCP)

> High-quality Model Context Protocol server for Gmail / Google Workspace.

**Status:** Planned / Coming soon

## Planned Tools

- `gmail_list_emails` – List / search emails
- `gmail_get_email` – Get full email content
- `gmail_send_email` – Send an email
- `gmail_reply` – Reply to a thread
- `gmail_create_draft` – Create a draft
- `gmail_modify_labels` – Add/remove labels
- `gmail_list_labels` – List available labels
- `gmail_trash` / `gmail_archive`

## Auth

- OAuth 2.0 (Google)
- Service Account (for Workspace)

## Why we build this

Gmail is one of the most requested integrations.  
We will provide a clean, secure, and well-documented MCP server.
